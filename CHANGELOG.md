# 2.0.0

- Animated GIFs work again. They are resized inside the browser, so nothing is sent to a third-party service.
- Animated WebP, AVIF and PNG images are converted to animated GIFs.
- Naming an emoji now happens in a small window with a preview, instead of a browser prompt. If a name is taken you can pick another without starting over.
- An emoji can be added to several workspaces at once.
- SVG images are supported.
- The options page opens in its own tab, shows whether you are signed in to each workspace, and accepts a pasted workspace address.
- Rebuilt on Chrome's Manifest V3. The extension no longer asks for the notifications permission.
